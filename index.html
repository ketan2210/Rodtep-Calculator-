Assessable value (INR)—
Formula: BCD amount ÷ BCD percentage × 100. Enter the percentage as a number, for example 7.5 for 7.5%.

03 · Net Weight from Assessable Value

Calculate estimated net weight from assessable value and unit price in INR per kg.

Net weight (kg)—
Formula: assessable value ÷ unit price. Use the unit price applicable to the calculation you are performing.

Calculation notes

Keep these points in mind while using the calculator.

  • All INR amounts are displayed to 2 decimal places.
  • Unit prices and weights can include decimals.
  • Blank or invalid inputs show as a dash instead of a misleading zero.
  • This is a calculation aid, not an official customs assessment.
